# FlightDeck Alpha Planning Docs

Use these files as the operating system for the hackathon build.

- [implementation-roadmap.md](implementation-roadmap.md): master step-by-step build plan.
- [phase-checklists.md](phase-checklists.md): tickable engineering checklists by phase.
- [acceptance-checks.md](acceptance-checks.md): regular pass/fail checks for demos, trading, safety, and submission readiness.
- [trading-runbook.md](trading-runbook.md): how to run the agent during market hours and what to do when things break.
- [submission-tracker.md](submission-tracker.md): final lablab submission checklist and asset tracker.
- [social-plan.md](social-plan.md): build-in-public schedule and post templates.

Primary rule: every feature must either improve judging score, improve trading safety, or improve demo clarity. Everything else is optional.
